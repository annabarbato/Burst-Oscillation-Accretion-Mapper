# Notebooks

This directory is reserved for exploratory analysis and visual review notebooks.

Rules:

- Notebooks are not the source of truth for catalog products, candidate classes, or published results.
- Reusable logic belongs in `src/` once the relevant roadmap phase begins.
- Paper or catalog figures must eventually be generated by reproducible scripts or pipeline steps, not hand-edited notebooks.
- Phase 0 should not add notebooks unless they are needed to document curation decisions.
